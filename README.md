# Telegram Store Bot 


Этот проект представляет собой Telegram-бота с логированием, антифлудом, кассой, рассылкой, и запуском через Docker.

## Возможности
- Поиск заказа в закрепленном сообщении в канале
- Отправка оформленного заказа в закрытую группу
- Техработы
- Анти-флуд система
- Логирование
- Касса (учет доходов и расходов)
- Рассылки с Celery и Redis
- Запуск в Docker

## Запуск

```bash
docker compose up --build -d


TOKEN=токен_вашего_бота
ADMINS=айди_админов
GROUP_ID=ваша_закрытая_группа
CHANNEL_ID=ваш_телеграм_канал
LOG_FILE=bot_logs.txt
